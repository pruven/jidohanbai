Bring your friends into the mix.

Run this app on each computer, set a shared PEER_TOKEN, and add each friend's Tailscale Serve URL to PEERS. Restart the app to connect.

tailscale serve --bg 3000

Detailed setup is in the project's README. The app never browses your computer: only contributed files are offered.

SERENDIPITY, EXPLAINED

A file exchange
with a surprise inside.

  1. Leave something good.

    Add a meme, artwork, or other harmless file. Only files you contribute are shared.

  2. Connect your friends.

    Each friend runs their own machine, connected with Tailscale and a shared peer token.

  3. Press. Open. Enjoy.

    Get a random file from another machine, streamed directly through your private network.

No friends connected yet? Local test mode lets you vend your uploads. Three starter files appear until you add your first contribution.
